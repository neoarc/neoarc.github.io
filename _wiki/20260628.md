# 밤새 켜놓은 컴퓨터

- 의도한건 아니지만 컴퓨터를 켜놓은채 잠드는 날이 많다.
- 주로 밤 늦게 컴퓨터를 사용할때가 많다보니, 좀 찌뿌둥하다 싶으면 잠깐 쉬다가 잠들기 일수
- 과거에는 불금엔 새벽 4시까지 깨어있다가 자기도 했는데, 이제는 초저녁에 잠들었다가 새벽에 깨서 컴퓨터를 사용하는 경우가 더 많았다.

# 탄냄새와 함께 사망

- 여느때처럼 컴퓨터를 켜놓고 잠들었던 다음날 아침 6~7시경
- 다시 컴퓨터를 좀 만지고 있는데 갑자기 그냥 꺼져버리는 컴퓨터
- 잠시후에 기계 탄 냄새가 나서 전원부터 내렸다.

# 하하하 ...?

- 나름 신속하게 대처했다고 뿌듯해하며 본체를 열어보니 메인보드의 한 칩에 그을린 자국이 있었다.
- 시대가 좋아져 메인보드 사진을 AI에게 보여줬더니 전원을 관리하는 칩이 탄 것이라고 했다.
- 다행이다. 램이나 SSD가 고장난게 아니라서....

# 메인보드 교체!

- 3년전 집에 들였지만 사실은 회사에서 5년을 사용한 상태였으니 당시엔 최신 컴퓨터였어도 이제는 8년이나 지난 구닥다리 컴퓨터
- 중고시장을 찾아보니 마침 같은 메인보드를 파는 사람이 있었다. 가격도 얼마 하지 않아서 바로 구매
- 조심조심 뜯어내고 조립했다.
- 컴퓨터를 직접 뜯고 조립해본게 10년만이라 조심스러웠다.

# 켜지긴 하는데...

- 메인보드만 같은걸로 교체하는데도 OS를 새로 깔게 될까봐 걱정했지만, 기존처럼 그대로 부팅되고 사용할 수 있게 되었다.
- 하지만 10분도 사용하지 못하고 PC가 자꾸 재부팅되는 이상현상이 계속해서 발생했다.
- 어쩔때는 블루스크린이 발생하기도 하고 증상이나 재부팅되는 타이밍이 불규칙적이었다.

# 삽질의 시작

- 상황은 오리무중이 되었다.
- 새로 산 메인보드가 불량인지, 다른 부품도 고장난건지 알길이 없었다.
- AI와 심각하게 상담을 나눈 결과 이런저런 벤치마킹 테스트를 해보면 뭐가 불량인지 추정할 수 있단다.
- 시간을 많이 할애할 수 없어서 조금씩 밖에 테스트하지 못했다.
	- 메인보드 부하 테스트
	- 디스크 테스트 
	- 램 테스트
	- ...
	- 모든 테스트는 정상. 걸린시간은 무려 1주일
- 상황을 설명하니 전원 제어칩이 탄건 파워서플라이가 불량이라서 그럴 가능성이 높댄다.
	- 그렇다면 파워서플라이 교체!!

# 파워서플라이 교체!!

- 아무렴, 10년 가까이 썼으니 파워서플라이도 수명이 많이 줄었을 것이다.
- 이왕 교체하는 김에 좀 더 좋은걸로 구매
- 그래도 증상이 그대로네?

# 메인보드 다시 교체!!!

- 운좋게 원래것과 같은걸로 살 수 있었던 메인보드가 불량은 아니었을까?
- 이런저런 테스트를 해봤지만 모두 정상인데도 자꾸 재부팅된다는 사유를 적어 반품했다. (판매자님 죄송)
- 이미 구닥다리가 된 CPU와 DDR4램을 그대로 사용해야했기에 호환되는 조금 더 좋은 메인보드로 다시 구매했다.
- 증상은 동일 💀

# 여기저기 수소문

- 더이상 돈을 버려가며 삽질을 할 수 없다고 생각했다.
- 커뮤니티에 글도 올려보고 틈만 나면 관련된 자료를 찾아다녔다.
- 크게 도움이 되는 정보를 얻진 못했다.
- 램도 뽑아서 다른 슬롯에 꼽아보고... 별짓을 다했다.

# CPU 밖에 없다

- 결국 CPU가 고장나서 재부팅이나 블루스크린이 발생한다는 결론에 도달했다.
- 8년전 최상급 CPU였지만 지금은 싸졌겠지? 는 나의 오산. i9-9900은 지금도 무려 50만원이 넘는 고가의 CPU였던 것이다.
- CPU를 교체해서 또 이러지 말라는 법도 없기에 함부로 구매하기가 꺼려졌다.
- 결국, 메인보드에 꼽을 수 있는 최하등급 CPU를 구매하게 되었다. 
- i3-8100. 2만원.
- 범인은 CPU가 맞았다. ...

# 똥컴

- 결국 메인보드와 파워, CPU까지 교체했지만 원래 사용하던 그대로 다시 살려낼 수 있었다.
- 물론 무거운 작업을 하면 멈춘다거나 엄청난 렉이 발생하는 똥컴을 쓰게 되었지만...
- 게임을 하지 않으니 사용성이 크게 다르지도 않았다...
- 이제는 컴퓨터 부품들이 너무 비싸져서, 언제 다시 컴퓨터를 바꿀 수 있을지 모르겠다.
- ~~CPU 교체로도 해결되지 않으면 그냥 좋은 노트북을 사려고 했지만 실패~~
